A matrix (plural "matrices") is a two-dimensional arrangement of values, typically organized in rows and columns. Matrices are often used to represent data or to describe transformations. Each value in a matrix is called an element, and the position of an element is specified by its row and column indices.

For example, a $2 \times 3$ (read as "2 by 3") matrix has 2 rows and 3 columns:

$$
A = \begin{bmatrix}
\ A_{11} & A_{12} & A_{13} \\
\ A_{21} & A_{22} & A_{23}
\end{bmatrix}
$$

Here, $A_{11}$ is the element in the first row and first column, $A_{12}$ is the element in the first row and second column, and so on.

## Notation

When a variable represents a matrix, it is common to use an uppercase letter, such as $A$, $B$, or $C$.

## Bracket conventions

Different types of brackets can be used to write matrices in different disciplines, such as:

- square brackets: $\begin{bmatrix} \cdots \end{bmatrix}$
- parentheses: $\begin{pmatrix} \cdots \end{pmatrix}$
